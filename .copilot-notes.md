# aphelion-web — repository notes

## Purpose
Official website for Aphelion Editor, a node-based video compositor for
desktop. Public domain: https://www.aphelion-community.com

## Two things that look true and are not

Both of these were asserted in an earlier version of this file and both were
wrong. They are called out first because acting on either one breaks the site.

**There is no static export.** `next.config.ts` does *not* set
`output: "export"`. This is a normal server-rendered App Router app: route
handlers exist (`app/api/docs/revalidate/route.ts`,
`app/api/sdk/download/route.ts`), `redirects()` and `headers()` in
`next.config.ts` are live, and the docs and product pages use ISR
(`export const revalidate = 60 | 120`). A stray 1.2 MB file named `out` in the
project root is an unrelated JSON dump, not a Next export directory — an
earlier note cited it as "proof" of static export.

**The project is not open source.** `pyproject.toml` in both `aphelion-editor`
and `aphelion-sdk` declares `license = "LicenseRef-Proprietary"`, and no
`LICENSE` file exists anywhere. The source is public and readable; that is not
the same as being licensed for reuse. Do not describe the project as open
source, and do not add a `license` field to structured data. `lib/site.ts`
holds the statement the site uses, with instructions for flipping it if the
licence ever changes.

## Stack

- Next.js 16 (App Router) with Turbopack, TypeScript, React 19
- Tailwind v4 via the `@tailwindcss/postcss` plugin
- HeroUI for components, `@gravity-ui/icons` for icons
- Docs are rendered from the markdown in the two product repositories, fetched
  from GitHub at runtime with a local-checkout fallback

## Source of truth for product facts

- Version: `aphelion-editor/src/config/constants.py` → `APP_VERSION`
  (currently **0.1.2**), mirrored in `lib/site.ts` as `EDITOR_VERSION`
- Node count: counted from the live registry, **172** across 21 categories —
  the site said 77 for a long time
- GitHub: https://github.com/aphelion-engine/aphelion-editor
- Python requirement: 3.11+; platforms: Windows (MSI), macOS and Linux from source

## Canonical host

`https://www.aphelion-community.com`, decided once in `lib/site.ts` and
`lib/seo.ts`. The apex host is 308-redirected by a host-scoped rule in
`next.config.ts`. That rule cannot be tested with `fetch` — undici drops a
caller-supplied `Host` header, so the request never looks like an apex one and
needs a raw socket.

## SEO conventions

`lib/seo.ts` is the single policy point: `SITE_URL`, `absoluteUrl()`, and
`pageMetadata()`. Every page builds its metadata through `pageMetadata`, so no
route can ship a title without a canonical or a canonical without a social card.

- Titles end `| Aphelion Editor`, or `| Aphelion Editor Documentation` for docs.
  The root layout's title template applies the same suffix to short titles.
- Descriptions stay under 160 characters. Google truncates beyond that, and
  eleven pages originally ran to 170–220.
- The root path is the bare origin, with no trailing slash, in the canonical,
  `og:url` and the sitemap alike.

### Verifying it

```bash
npm run audit:seo                      # built output only, no server
npm run build && npm run start         # then, in another shell:
npm run audit:seo:live                 # also crawls docs pages and runtime
```

The audit encodes the specific defects that actually shipped — a
`/docs/.../README` URL, markdown table delimiters leaking into descriptions, a
sitemap/canonical trailing-slash mismatch, mixed title separators, over-long
descriptions, an indexable 500 page. It exits non-zero, so it can gate a
release. Documentation pages are server-rendered on demand and never appear in
`.next` as HTML, which is why the docs checks need the live server.
