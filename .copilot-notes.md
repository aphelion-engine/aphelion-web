# aphelion-web — repository notes

## Purpose
Official website for Aphelion Editor (open-source node-based video
compositor/editor). Public domain: https://www.aphelion-community.com

## Stack
- Next.js App Router (TypeScript)
- Tailwind v4 (PostCSS plugin `@tailwindcss/postcss`)
- Static export (`output: "export"`) — there is no Node server at runtime
  - Verified by `out/` directory and `next.config.ts`

## Critical constraint: static export
`output: "export"` means:
- No Route Handlers, no middleware, no `next/headers` runtime APIs
- `robots.txt`, `sitemap.xml`, `llms.txt` must be generated as *static
  files* (`app/robots.ts` / `app/sitemap.ts` with `dynamic = "force-static"`,
  or literal files in `public/`)
- 404 page is `app/not-found.tsx` (works, but always served by the host)
- Redirects go in `next.config.ts` under `redirects()` — exported as static
  redirect stubs only if host supports it; otherwise document host rules

## Source of truth for product facts
- Version: `src/config/constants.py` → `APP_VERSION` in `aphelion-editor`
  (currently **0.1.2**)
- GitHub: https://github.com/aphelion-engine/aphelion-editor
- Python requirement: 3.11+
- Platform: Windows installer (MSI)
